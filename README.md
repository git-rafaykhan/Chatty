# 💬 Chatty – Real-Time Chat Application

🔗 **Live Demo:** [Chatty App](https://chatty-sdul-git-main-git-rafaykhans-projects.vercel.app/login)

**Chatty** is a real-time group and individual chat application built with modern web technologies.  
It supports secure messaging, user authentication, contact management, and instant communication via WebSockets.

---

## ⚙️ Tech Stack

| Layer      | Technology                        |
|------------|-----------------------------------|
| Frontend   | React, Tailwind CSS, Axios        |
| Backend    | Node.js, Express.js, MongoDB      |
| Realtime   | Socket.io                         |
| Auth       | JWT (JSON Web Token)              |
| Deployment | Vercel (Frontend), Render (Backend) |

---

## ✨ Features

- 🔐 Secure JWT-based Login & Signup  
- 💬 One-to-One & Group Chat  
- 🟢 Real-Time Messaging with Socket.io  
- 🧾 Persistent Chat History & Message Timestamps  
- 👥 Contact Management (Add/Remove Contacts)  
- ✨ Typing Indicator *(coming soon)*  
- 📱 Fully Responsive (Mobile & Desktop)
